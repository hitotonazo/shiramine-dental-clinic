# 白峰デンタルクリニック ARGサイト

## 01｜通常サイト・ページ仕様

### index.html

目的：完全に普通の地域歯科医院として認識させる。

Header：ロゴ／当院について／診療案内／院長・スタッフ／コラム／アクセス／WEB予約。

Hero：`clinic-hero.jpg`＋`clinic-logo.png`
コピー「親子三代で通える、地域の歯医者さん」。
初回は研究・監視・保存対象等の語を出さない。

当院について：`clinic-reception.jpg`。地域密着、家族で通える、丁寧な診療。

診療案内： - 一般歯科 `treatment-general.jpg` - 小児歯科
`treatment-child.jpg` - ホワイトニング `treatment-whitening.jpg` -
予防歯科は用意済み画像があれば使用。なければ既存画像で無理なく構成。

特徴：丁寧な説明／予防重視／家族で通いやすい／清潔な院内。

院長紹介：`director.jpg`。写真＋短い挨拶。

院内紹介：`clinic-reception.jpg`等。複雑なコラージュ禁止。

コラム：普通の記事4〜6件。その中に「抜歯した歯はどうなるの？」を自然に混ぜ、`column-tooth.html`へ。初期状態ではカードを異常に見せない。

お知らせ：一般的なお知らせ3件程度。
Access：架空情報で統一。実在施設と誤認させる実住所・電話番号は使わない。
Footer：ロゴ、ナビ、診療時間、copyright。

### column-tooth.html

タイトル「抜歯した歯はどうなるの？」 画像：`column-extraction.jpg`
冒頭は一般患者向けコラム。

処理フローはHTML/CSS： 通常：抜歯 → 洗浄・消毒 → 患者へ返却／医療廃棄
異常：抜歯 → 洗浄・消毒 → ［モザイク］ → 院内保管

モザイクがPHASE1の唯一の重要操作。
誰でも意図的な隠蔽と判断できる見た目にする。

初回クリック： 1. modulesの改変演出 2. モザイク解除 3. 「保存対象」露出
4. 「保存対象管理記録を確認」出現 5. phase進行

2回目以降：演出再生なし。解除済み状態を表示しrecords.htmlへ通常遷移。

### Ending後 index.html

Heroコピー下に「これからも、地域の皆さまとともに。」を追加。
その他はほぼ通常状態。真相後に「観察継続」とも読める静かな余韻にする。

### レスポンシブ
