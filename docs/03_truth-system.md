# 白峰デンタルクリニック ARGサイト

## 03｜TRUTH・Ending仕様

### 1. 目的

PHASE1〜3の発見をSHIRAMINE PROJECTへ回収する。
新しい謎を増やさず、次に答える：
なぜ歯か／なぜ生活行動か／なぜ町民全体か／なぜ転入が続いたか／白峰町は何のためか。

### 2. デザイン

「長期間隠されていた研究計画の内部資料」。
黒〜濃紺、オフホワイト、グレー、低彩度緑。赤はCONFIDENTIAL/WARNING等のみ。
不気味だが黒赤＋激しいグリッチの安価なホラーは禁止。
本文14px未満禁止。SP横スクロール禁止。

画像：`truth-tissue.jpg`、`truth-shiramine-archive.jpg`
画像内の生成文字を正式情報として読ませず、正式情報はHTMLで表示。

### 3. BIOLOGICAL SCREENING

一部の人間には通常より高い組織修復反応がある。
身体へ明確に現れる前でも歯の内部組織に特徴的反応が現れる。
白峰デンタルは通常診療を通じて生体サンプルを取得し、特殊な人物を早期選別していた。
`truth-tissue.jpg`を使用。 PHASE2「組織修復反応」を回収。

### 4. LONG-TERM OBSERVATION

居住・教育・就労・医療・町内生活を長期記録。
白峰デンタルの記録は町内施設の記録と接続。
PHASE3の人生単位の履歴を回収。

### 5. CONTROL POPULATION

特殊対象者だけでなく比較対象を含め町内生活を追跡。
登録住民1,842／追跡中1,791／追跡率97.2%。 PHASE3の大量の点を回収。

### 6. SETTLEMENT RECORD

`truth-shiramine-archive.jpg`
1978年以降、全国各地から対象候補を白峰へ誘導。
長期観察のため住宅・仕事・学校・医療等を整備。
ここで初めてPHASE3の大量転入が偶然ではないと断定。

### 7. SHIRAMINE PROJECT

計画図はHTML/CSS： 第I期 対象者選定 → 第II期 集住環境整備 → 第III期
長期生活観察 → 第IV期 環境適応評価 → 第V期 地域外展開

結論： 特殊な人間が白峰にいたから研究したのではない。
特殊な人間を長期観察するため、人を集め、生活させ、追跡できる白峰という環境自体を作った。
白峰デンタルは「生体サンプル採取・対象者選別」担当。

### 8. 隠蔽理由

現在も第IV期が続く。
研究対象が研究を知らず普通に暮らすこと自体が研究条件。
公表されると無断選別、移住誘導、医療データ利用、施設横断追跡が明らかになり観察条件が崩壊する。

### 9. Ending

第I期 対象者選定：完了 第II期 集住環境整備：完了 第III期
長期生活観察：継続中 第IV期 環境適応評価：終了予定 第V期
地域外展開：候補地域 選定済

最後：「次期観察環境候補の選定を開始します。」

プレイヤーの現在地取得、端末情報取得、本人を研究対象扱いする等の無理な巻き込みは禁止。

### 10. X共有

必須ボタン「調査結果を共有する」

共有文：
親子三代で通える歯医者。「白峰デンタルクリニック」を調査しました。 #ARG
#白峰デンタルクリニック

ネタバレ語を入れない。公開URLは設定値として差替可能にし、仮URLをハードコードしない。

### 11. Ending後

endingフラグ保存→index.html。
Hero下へ「これからも、地域の皆さまとともに。」を追加。
それ以外はほぼ通常状態。

### 12. 完了条件

保存対象、組織修復反応、生活行動記録、97.2%追跡、1978年以降の転入、白峰町の役割を全て回収。
第V期地域外展開で余韻を残し、X共有とEnding後TOP変化が機能する。
