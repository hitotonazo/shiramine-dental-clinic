# 白峰デンタルクリニック ARGサイト

## 02｜PHASE・records.html・ゲーム進行仕様

### 基本

異常発見 → 調査 → 画面変化 → 新情報 → 次の操作理由。
各段階で次の重要操作は原則1つ。

### PHASE2｜保存対象管理記録

`records.html`
通常Headerは使わず「歯科医院の古い内部管理システム」。TRUTHほど暗くしない。

表示： SHIRAMINE DENTAL CLINIC / INTERNAL RECORD

  ID         採取年 採取理由     反応値
  -------- -------- ---------- --------
  SH-018       2001 乳歯           87.2
  SH-026       2007 智歯           91.8
  SH-033       2015 治療抜歯       89.4
  SH-041       2021 智歯           96.1
  SH-052       2026 乳歯           99.4

各`specimen-shXXX.jpg`を使用。SH-052は黒容器＋緑液体で明確に差別化。
一般患者平均12.6／保存対象平均92.8。
反応値を調べた際、「反応値」が一瞬「組織修復反応」に変化してよい。

理解：「歯ではなく特殊な身体反応を持つ人間を選別している」
次の重要導線：SH-052「生活行動記録を確認」。

### PHASE3方針

旧案の「大量の移動線」は禁止。採用は「簡易地図＋生活行動記録」。
背景：`shiramine-map.jpg`
地図＝主要施設・最終記録地点・全住民観測の視覚化。
生活履歴＝HTMLタイムライン。

### STEP1｜SH-052

PC：左地図／右プロフィール＋タイムライン。SPは1カラム。

地点：住宅、白峰小学校、白峰中学校、白峰中央医院、白峰工業、白峰デンタル。
最終地点は点＋`SH-052 / LAST RECORDED LOCATION`をHTMLで重ねる。

履歴： 2008 白峰小学校 入学記録 2014 白峰中学校 登録記録 2020 白峰工業
勤務開始 2023 白峰中央医院 受診記録 2026 白峰デンタル
来院・保存歯サンプル採取

確認後のみ「他の保存対象者を表示」。

### STEP2｜他の保存対象者

SH-041 / SH-033 / SH-026 / SH-018へ切替。
地図画像は共通。点・プロフィール・タイムラインだけ変更。
5人全員確認必須にはしない。「複数人にも長期記録」が理解できれば進行可能。
確認後のみ「全登録住民」を出す。

### STEP3｜全登録住民

地図上に多数の小点を追加。 登録住民1,842／追跡中1,791／追跡率97.2%。
タイトル「対象者生活行動記録」→「白峰町生活行動記録」。

1,791個の正確な座標は不要。町全体が観測対象と一目で分かる密度でJS生成可。
重いcanvas不要。 表示完了後のみ「最古の記録を確認」。

### STEP4｜最古の記録

複雑な地図アニメーションは禁止。登録履歴・年代・転入数の記録表示へ切替。

開始：登録住民0／追跡対象0 1978年5月 転入12名 1978年6月 転入8名
1978年7月 転入15名

ここでは「意図的に集めた」と断定せず疑問を残す。 最後に「SHIRAMINE
PROJECT／内部資料を確認」だけを出しtruth.htmlへ。

### 解放順

SH-052 → 他対象者 → 全登録住民 → 最古記録 → SHIRAMINE PROJECT。
最初から同時表示禁止。

### 直接アクセス

phase不足でrecords/truthの核心情報を表示しない。通常サイトへ戻すか簡潔な権限不足表示。

### debug/reset

modules既存debugを使用。
phase、各フラグ、切替、resetを確認可能にする。本番UIへ露出しない。
resetはshiramine系状態を初期化。

### 改変演出

modulesのみ使用。初回重要異常時だけ。
PHASE3の対象者切替・タブ切替ごとに再生しない。
